An entry for the make.fun contest "One Emoji, One Smile" — exactly one emoji, the one most likely to make a stranger smile. The program `main.ts` (Node 22, standard library only, no network, no randomness) deterministically writes a single emoji to `/output/entry.txt`: 🫶, two hands shaping a heart — a small gesture of warmth offered to a stranger, chosen rather than the default smiley.
